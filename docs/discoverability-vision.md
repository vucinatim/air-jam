# Air Jam Framework Discoverability Vision

Last updated: 2026-10-09
Status: guiding public direction

Air Jam should be easy for people and agents to find, understand, install and
integrate. Public clarity should reflect the actual framework and its
relationship to the separately operated product.

## Truth density over content volume

Keep one canonical explanation per concept, real examples and explicit
package roles. Reject thin search pages, alternate-wording duplicates,
unmaintained machine endpoints and claims about unsupported internals.

The public repository, npm packages, creator pages and hosted website should
tell the same story: an open self-hostable foundation with optional managed
creation and distribution. Studio does not replace or privately improve the
public game contract.

## Clear entrypoints

`create-airjam` starts a project; the SDK authors its game; the server runs its
rooms; the CLI and MCP expose development, inspection and publishing clients.
Environment, harness and devtools libraries are reusable supported modules,
not another mandatory product.

Creator pages have one authored public source and are delivered to the website
and agent tools from the packaged snapshot. Stable URLs and truthful metadata
should lead agents to maintained guidance rather than a second shadow manual.

## Product and framework ownership

The private product owns its homepage, catalog, blog, launch campaigns and
distribution implementation. This repository owns package descriptions,
creator documentation, reference examples and framework release notes.

Source ownership should not fracture public identity: Air Jam remains one
ecosystem. It should be obvious what works locally without an account and what
uses the managed product.

## Quality test

Every public surface should make at least one real job easier: finding the
project, understanding the model, installing the right package, building a game
or verifying a supported claim. If a discovery tactic adds noise, duplicates
ownership or overpromises, it is the wrong direction.
